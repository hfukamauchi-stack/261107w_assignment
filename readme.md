# ①課題名
8BIT JANKEN SURVIVAL（8bitじゃんけんゲーム）

## ②課題内容（どんな作品か）
- じゃんけんでCPUと対戦し、10連勝を目指すレトロゲーム風のWebアプリ。
- 勝利すると連勝数が増加し、敗北すると0にリセット、引き分けの場合は連勝数が維持される仕組み。
- 連勝数に応じて画面下部のメーターが蓄積され、10連勝するとゲームクリアとなる。
- 過去最高連勝数をブラウザに保存し、次回プレイ時にも確認できる。

## ⑤工夫した点・こだわった点
- 1980年代のファミコンやアーケードゲームをイメージし、8bit風のドット感を意識したUIデザインにした。
- タイトル画面、対戦画面、ゲームクリア画面の3つに分け、実際のゲームのような画面遷移を実装した。
- 勝敗によって連勝数が変化するルールを設定し、連勝メーターによってプレイヤーが目標までの進捗を視覚的に確認できるようにした。
- localStorageを活用し、過去最高連勝数をブラウザ上に保存できるようにした。

## ⑥難しかった点・次回トライしたいこと（又は機能）
- HTML・CSS・JavaScriptを組み合わせ、画面遷移やゲームの状態管理を実装すること。
- 勝利・敗北・引き分けそれぞれで連勝数やメーターの状態が正しく変化するようにすること。
- 今後は効果音やアニメーションを追加し、ゲームとしての臨場感を高めたい。
- 連勝数に応じた称号やランキング機能なども実装してみたい。
